## Projetos em Destaque

### 🎫 [CompassEvent](https://github.com/janainafmonteiro/ANMAR25_D03_COMPASSEVENT)
* **O que faz:** API para gestão de eventos — cadastro de usuários, criação de eventos e controle de inscrições com controle de acessos por papel (admin, organizador, participante).
* **Tecnologias:** NestJS · TypeScript · AWS (S3, DynamoDB, SES) · JWT
* **Escopo:** Projeto individual (Compass UOL)

### 🏢 [CompassReservation](https://github.com/CodeBuilders-COMPASS/ANMAR25_D02_COMPASSRESERVATION)
* **O que faz:** API para reserva de espaços corporativos, com validações de conflitos de agenda e regras de disponibilidade. Atuação no desenvolvimento dos módulos de *Spaces* e *Reservations*.
* **Tecnologias:** NestJS · TypeScript · Prisma · PostgreSQL · JWT
* **Escopo:** Projeto em equipe (4 devs)

### 🎮 [ProDrafts] (https://prodrafts.tech/)
* **O que faz:** Simulador de draft (picks & bans) de League of Legends com sugestões de campeões via modelo de IA treinado com dados de partidas profissionais.
* **Tecnologias:** Java · Spring Boot · React · Python · FastAPI · scikit-learn
* **Escopo:** Projeto em dupla
